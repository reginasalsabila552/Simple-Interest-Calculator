# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## Project Overview

This project provides a command-line calculator that computes simple
interest. The user enters the principal amount, the annual interest rate,
and the time period, and the script prints the resulting interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Interactive input for principal, interest rate, and time period
- Result rounded to two decimal places
- Lightweight, written in plain Bash

## Usage

1. Clone this repository.
2. Make the script executable: `chmod +x simple-interest.sh`
3. Run it: `./simple-interest.sh`
4. Enter the principal, the rate (%), and the time (years) when prompted.

## Example

Principal: 1000, Rate: 5%, Time: 2 years → Simple Interest: 100.00
